# App Candidaturas 

## Objetivo 

Desenvolver uma aplicação web multiusuário que permita centralizar vagas de emprego, salvar oportunidades de interesse e acompanhar o status das candidaturas de forma individual e organizada.

## Stack

PostgreSQL
| Python
| Git/Github

## Ferramentas

VsCode
| Github Desktop
| Dbdiagram

## Modelagem do banco de dados

A modelagem de dados foi desenvolvida para organizar as informações das vagas de emprego e acompanhar o processo de candidatura dos usuários. O banco de dados contempla tabelas para armazenar usuários, vagas, empresas, candidaturas e histórico de etapas, estabelecendo relacionamentos entre elas para permitir o gerenciamento das vagas salvas e o acompanhamento individual das candidaturas.
